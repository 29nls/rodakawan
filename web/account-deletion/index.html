Hapus data RodaKawan

RodaKawan tidak memakai akun, email, atau kata sandi. Data Anda terikat pada satu identitas anonim di perangkat yang Anda pakai, jadi penghapusan dilakukan dari dalam aplikasi — di tempat identitas itu berada — bukan dari halaman ini.

1. Cara menghapus data Anda

  1. Buka aplikasi RodaKawan di perangkat yang biasa Anda pakai.
  2. Masuk ke tab Profil → Hapus data saya.
  3. Ketik username Anda persis seperti yang tampil di profil, lalu tekan tombol hapus.
  4. Tunggu sampai layar menyatakan server selesai. Aplikasi lalu membuat identitas anonim baru yang belum menjadi anggota klub mana pun.

2. Yang terjadi setelah data dihapus

  • Identitas anonim perangkat ini dihapus, bersama profil, foto profil, kendaraan, nomor polisi, catatan privat, token notifikasi, lokasi terakhir, relasi follow, dan blokir.
  • Anda keluar dari klub dan perjalanan. Kepemilikan klub/perjalanan dialihkan ke pengelola lain; perjalanan tanpa penerus dibatalkan. Perjalanan tetap ada untuk peserta lain.
  • Laporan bahaya tetap tersimpan untuk keselamatan peserta lain, tanpa identitas Anda.
  • Pesan konvoi serta postingan/komentar diredaksi dan diatribusikan ke “Pengguna dihapus”. Jejak audit moderasi tetap ada tanpa identitas Anda.
  • Penghapusan tidak bisa dibatalkan dan data lama tidak dapat dipulihkan.

3. Bila aplikasi tidak dapat dibuka

Identitas anonim hanya ada di perangkat itu dan tidak bisa dipulihkan dari luar, termasuk lewat halaman ini: tidak ada email atau kata sandi untuk membuktikan kepemilikan. Bila perangkat hilang atau aplikasi tidak bisa dijalankan, hubungi halaman dukungan dan jelaskan kendalanya — jangan mengirim token, tangkapan layar berisi data pribadi orang lain, atau koordinat lokasi.

Rincian retensi ada di Kebijakan privasi. Halaman ini tidak memerlukan JavaScript dan tidak mengirim data apa pun ke server.
